# 🎉 Happy Birthday Trần Hoàng Anh (29.10) — Awwwards Digital Experience

Trang web nghệ thuật tương tác phong cách Awwwards mừng sinh nhật đặc biệt dành riêng cho **Trần Hoàng Anh (29.10)**.

## ✨ Điểm nổi bật
- **Giao diện Awwwards**: Thiết kế Dark Obsidian với Chromatic Mesh Gradient, hiệu ứng hạt ánh sáng, Typography nghệ thuật.
- **Tác phẩm Vector 60FPS**: Hệ thống chuyển động quỹ đạo (Orbit), nhịp tim tần số (Pulse), và cấu trúc vô cực (Infinity Photon).
- **Thổi nến & Lời chúc**: Tương tác thổi tắt ngọn nến sinh nhật và mở khóa thông điệp.
- **Âm thanh tổng hợp (Web Audio API)**: Tự tạo giai điệu du dương mộc mạc trực tiếp trên trình duyệt, không phụ thuộc file mp3 ngoài.
- **Responsive Mobile First**: Tối ưu mượt mà cho trải nghiệm trên điện thoại thông minh.
